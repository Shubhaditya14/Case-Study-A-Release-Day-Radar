# Reflection notes (kept as we go — feeds report section i)

Dated, factual notes on what changed and why. Written during the build, not afterwards.

- **2026-11-26 (Phase 1)** — Started from question-bank Q1 (trailer engagement → opening weekend), with a sentiment add-on: "does sentiment add anything beyond raw views?". Wikipedia MediaWiki API confirmed working for the test film (Chhaava — infobox has a Box office row). TMDb and YouTube waiting on keys.
- **2026-11-26 (Phase 1)** — Tooling choice: Python 3.12 venv (not the system 3.14) because PySpark 3.5 does not yet support 3.14. Spark local mode confirmed running on Java 21.
- **2026-11-26 (Phase 1)** — Port 3306 was already used by a pre-installed MySQL, so the project's MySQL 8.0 runs in Docker on host port 3307. Lesson: check ports before assuming defaults.
- **2026-11-26 (Phase 1)** — IMDb 50K check: 50,000 rows, perfectly balanced 25k/25k, 0 nulls, but 418 duplicate review texts — to be logged and decided in the cleaning stage.
- **2026-11-26 (Phase 1, film list)** — Big finding: Wikipedia does not report "opening weekend" consistently. Of 18 candidates, only 10 state a first-weekend figure; others give opening *day* only, or nothing. The figures also mix worldwide gross vs India net, 3-day vs 4-day (Thursday) weekends, ₹ ranges, and one is in USD. This forced decisions on the outcome metric (per-day weekend average, flags for domestic-only/USD) before any analysis.
- **2026-11-26 (Phase 1, trailers)** — Pan-India films release one trailer per language (Kantara: Chapter 1 = Hindi 39.6M, Kannada 23.9M, Telugu 18.6M views on the same day). Counting only one version would undercount regional films. Also the naive "most-viewed trailer" search picked wrong videos twice (a 2026 OTT trailer for Sitaare Zameen Par; the sequel's trailer for Dhurandhar) — trailer search must be limited to before the release date.
- **2026-11-26 (Phase 1)** — Wikipedia returned HTTP 429 until requests carried a descriptive User-Agent with a contact URL.
- **2026-11-26 (Phase 2, Trends)** — All 10 Trends exports complete with no missing days. Every film peaks on release day or within 3 days after (not on trailer day), so search interest tracks release more than trailer launch. Google Trends writes very low values as the text "<1" (4 days for Chhaava), which needs a type-casting decision.
- **2026-11-26 (Phase 2, trailers)** — Searching a film's own channel for "trailer" returned launch-event livestreams, actor speeches and 15-second Shorts (Peddi: 16 hits, 1 real trailer). Switched to a structural rule: a language version must be the same edit, i.e. within 10% of the main trailer's length. Result: only Dhurandhar: The Revenge and Kantara: Chapter 1 had 5 dubbed versions each; the rest have one. Sitaare Zameen Par's Tamil/Telugu dubs came out 4 weeks later, so they fall outside the 3-day window (noted as a limitation).
- **2026-11-26 (Phase 2, comments)** — Dropped the "~5,000 comments per film" cap from the plan: the API returns newest comments first, so a cap would contain no trailer-week comments at all. We page back through every top-level comment of each main trailer instead (≈1 unit per 100 comments).
- **2026-11-26 (Phase 3, framing)** — Realised the YouTube API only returns a trailer's view count *today*, not during trailer week, so "trailer-week views" cannot be measured directly — today's views include everyone who watched after release (reverse causation risk: a hit film's trailer keeps collecting views). Comment timestamps DO give true trailer-week activity. The question is refined to: "Did trailer-week comment activity and sentiment (and total trailer views, with that caveat) line up with first-weekend collections?"
- **2026-11-26 (Phase 3, a correction that changed the answer)** — Found 16,245 Raid 2 comments posted up to 20.7 h *before* the trailer's official API publish time (it was viewable earlier). Started every trailer window at the earlier of the publish time and the first comment. This one fix moved the first-week-comments correlation from ρ = 0.56 to 0.37 and the leave-one-out Buzz Index from 8/10 to 6/10 correct calls. Total trailer views stayed at ρ = 0.65. Lesson: with n = 10, a single film's data error can flip a conclusion, so we report the corrected, weaker result.
